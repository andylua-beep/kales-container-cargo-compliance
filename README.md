- **100% Local & Zero-Build**: Runs completely offline inside Chrome via `chrome.storage.local`.

## Installation (Chrome Developer Mode)

1. Download **`kales-container-cargo-compliance-v1.0.0.zip`** from [GitHub Releases](https://github.com/andylua-beep/kales-container-cargo-compliance/releases/latest) (or clone this repository).
2. Unzip the archive (or use the cloned repository root directory).
3. Open Google Chrome and go to `chrome://extensions/`.
4. Enable **Developer mode** in the top-right corner.
5. Click **Load unpacked** and select the folder containing `manifest.json`.
